Questions fréquentes

Le QR code ne s'affiche pas

Attends quelques secondes après avoir choisi ton nom de session — le temps que la connexion WhatsApp s'initialise. Si rien n'apparaît après 30 secondes, recharge la page.

Le bot ne répond pas après la connexion

Vérifie que ton message commence bien par le préfixe . (par exemple .ping). Si tu viens de scanner, laisse 10 à 15 secondes au bot pour terminer sa synchronisation.

Je veux connecter un deuxième numéro

Change simplement le nom de session ci-dessus pour un nouveau nom, puis scanne ou pair ton autre numéro. Les deux resteront connectés en même temps, sans se gêner.

Le code de pairage ne fonctionne pas

Vérifie que le numéro est complet avec l'indicatif du pays (ex : +509...), sans espaces. Le code expire après environ une minute : redemande-en un nouveau s'il a expiré.
